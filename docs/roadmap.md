# Roadmap

Where Octotally is heading, roughly in order. Open an issue or a discussion if one of these
matters to you or if something is missing.

- GitHub OAuth login instead of a personal access token (a second `TokenSource`)
- MCP endpoint ("what is pending on GitHub?") for agents
- Write actions: comment, close, mark a discussion answered
- More notifiers: ntfy, Apprise, generic webhook
- Prometheus `/metrics`
